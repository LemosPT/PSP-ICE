# Security Policy

## Supported Versions

These are the versions that will receive security updates and be fully supported (we are in version 0.1.5):

| Version | Supported          |
| ------- | ------------------ |
|  0.1.5  | :white_check_mark: |
|  1.0.0  | :x:                |
|  2.0.0  | :x:                |
| <3.0.0  | :x:                |

## Reporting a Vulnerability

If you detect an Issue, critical error or a vulnerability, you can open an Issue at our [Issues Page](https://github.com/LemosPT/PSP-ICE/issues) or [join our Discord](https://discord.gg/fgsxAYRT6K) to receive direct support.
