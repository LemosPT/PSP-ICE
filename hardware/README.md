# Hardware

The hardware notes for PSP-ICE are maintained in [docs/hardware.md](../docs/hardware.md).

That page records the initial PSP-2004 target, intended iPhone host, tested hotspot arrangement, PSP-to-AUX audio path, development equipment and future physical-installation considerations.

Compatibility claims are deliberately conservative: the documented test setup is not a guarantee that every PSP, iPhone, iOS version or Wi-Fi access point has been validated.
