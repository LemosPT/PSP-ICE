# Protocol

The protocol documentation is maintained in two places:

- [Protocol notes](../docs/protocol.md) — current v1 packet header, channels, implemented audio/input payloads, known code discrepancies and current network behaviour.
- [Transport specification](specification.md) — broader design goals and proposed video-fragment format.

The protocol is an early UDP prototype. Do not treat proposed video transport, pairing, discovery, authentication or reconnect behaviour as implemented features.
