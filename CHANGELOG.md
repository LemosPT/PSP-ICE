# Changelog

Notable project-level changes. This is a concise milestone log, not an exhaustive list of every commit.

## 2026-11-05

- Clarified in the README that PSP-ICE is CarPlay-inspired and is not an Apple CarPlay implementation or certification.

## 2026-11-04

- Added a PDF documentation/user-manual item to the project status checklist.

- Shifted the architecture toward an audio-first design in which the PSP remains the audio playback endpoint.

- Recorded the PSP audio receiver and hardware audio-routing prototype milestones.
